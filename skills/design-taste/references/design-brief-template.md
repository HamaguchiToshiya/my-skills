# design-brief.md 雛形（design-taste の参照資料）

`../SKILL.md`（design-taste）「パイプライン連携: design-brief.md 雛形」から読む雛形の正。ディレクター（本体）→デザイン制作エージェント（`designer`）の受け渡しは以下の形式で行う（各欄の決め方は SKILL.md の Phase 1〜3c、数値の実体は `phase4-hard-rules.md`）。

```markdown
# Design Brief: 〈案件名〉

## Design Read
〈ページ種別〉を〈オーディエンス〉向けに、〈トーン語彙〉の方向で作る。

## 対象と入力
- 対象ページ一覧: 〈TOP / 下層◯◯ / …〉
- ワイヤーフレーム: 〈wireframe/ 等の所在。無ければ「なし」〉
- 支給素材: 〈materials/ 等の所在（画像・ロゴ・原稿）〉
- 参考調査レポート: 〈design-research-report.md へのリンク（あれば）〉

## ダイヤル
VARIANCE: n / MOTION: n / DENSITY: n

## テイストファミリー
主軸: 〈A〜E〉（従: あれば）
LLM向けスタイル名: 〈Swiss Design 等。Phase 3 の各ファミリー既定値から。使わないなら「なし」〉
　離し方: 〈骨格だけ借りて何で離すか。例: 色はブランドの朱、見出しは明朝〉

## 参考DNA（Phase 3b の4観点で要素単位に分解。ピクセルコピー禁止）
- 構造: 〈どの参考に従うか＋要点〉
- 配色ロジック: 〈色そのものは借りない。既存ブランド資産が優先〉
- タイポ: 〈例: ファット系見出し＋ゴシック本文〉
- 密度・余白: 〈例: 余白広め、1画面1メッセージ〉
- 参考スクショ: 〈design-research-assets/ の所在。無ければ「なし」〉

## FVコンペ結果（Phase 3c。スキップ時は理由を1行）
- 提示: 案A〈1行の意図〉 / 案B〈〉 / 案C〈〉（fv-comp/ 所在）
- 選択: 〈案◯〉＋コメント: 〈例: 構図はA、タイポの強さはBに寄せる〉

## デザイントークン初期値
- 色: --color-base / --color-main / --color-accent1 ...
- タイプスケール: 本文16px × 比率1.25（h2: SP32px → PC48px 等、主要段を明記）
- 角丸: --radius-s/m/l　- 影: --shadow-…　- 余白スケール: 8px基準

## ファーストビューの型
〈4-7の表から選択。例: スプリット（写真右・コピー左）〉

## 禁止事項（この案件固有）
- 〈例: 競合◯◯社に似せない / 赤系は使わない〉

## 原稿状況
- 支給済み: 〈〉 / 原稿待ち: 〈〉
```
